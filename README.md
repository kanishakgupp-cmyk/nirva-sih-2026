# NIRVA SIH 2026

NIRVA — Online-first evidence workflow prototype for SIH 2026.

## Development
This project is being developed using GitHub Codespaces.

The runtime request path is `Flutter -> FastAPI -> Supabase/PostgreSQL + Storage`. Django is planned later as an internal admin/control-plane component, not as part of the Flutter request path.

> Prototype uses safe mock/demo data only.
